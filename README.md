PomidorQA — автотесты
Автотесты для сервиса PomidorQA, выполненные в рамках марафона «Автоматизация на Playwright + TypeScript».

## О ПРОЕКТЕ

## Проект содержит автотесты на трёх уровнях:

Unit — проверка отдельных функций без браузера и сети.
API — проверка HTTP-сценариев через локальный mock-сервер.
E2E — проверка пользовательских сценариев в браузере на сервисе PomidorQA.

## Стек:
- TypeScript
- Playwright
- ESLint
- GitHub Actions

## Установка:
Требуется Node.js.
npm ci
npx playwright install chromium

## Запуск:

- Запустить все тесты: npm test
- Unit: npm run test:unit
- API: npm run test:api
- E2E: npm run test:e2e
- ESLint: npm run lint

## HTML-отчёт:
npm run report

## Что покрыто:

## Unit:
- пересечение временных слотов;
- отображение времени в разных часовых поясах;
- валидация пароля при регистрации.

## API:
- регистрация нового пользователя;
- повторная регистрация с существующим email;
- бронирование свободного слота;
- попытка забронировать собственный слот;
- бронирование слота в прошлом;
- бронирование несуществующего слота;
- повторное бронирование занятого слота;
- конкурентная попытка двух пользователей забронировать один слот.

## E2E:
- заполнение и сохранение данных профиля;
- добавление и проверка навыков;
- поиск пользователя в каталоге;
- отображение пользователя в каталоге при наличии свободного слота;
- бронирование встречи;
- отображение бронирования у гостя и хоста;
- отмена встречи;
- вход с неверными данными.

## CI:

GitHub Actions запускает установку зависимостей, ESLint и Playwright-тесты на push и pull_request
